# User Activity Analysis Dashboard

## 📊 Project Overview
This project presents an interactive Tableau dashboard that visualizes application usage and time spent across various activities. It provides insights into productivity trends and digital behavior.

## 🎯 Objectives
- Analyze time spent across different applications.
- Identify productivity patterns.
- Gain insights into user behavior.
- Enable interactive filtering and exploration.

## 🛠️ Tools & Technologies
- Tableau
- Data Visualization
- GitHub
- Microsoft Excel/CSV

## 📈 Dashboard Features
- **Top Applications by Usage Time:** Highlights the most-used applications.
- **Time Spent by Activity:** Categorizes usage into Work, Entertainment, Social, Study, and Break.
- **Interactive Filters:** Filter by App and Activity.
- **Sequential Color Palette:** Enhances visual clarity and interpretation.

## 📂 Files in This Repository
- `User_Activity_Analysis_Dashboard.twbx` – Packaged Tableau dashboard.
- `README.md` – Project documentation.

## 🚀 How to Use
1. Download the `.twbx` file.
2. Open it using Tableau Desktop or Tableau Public.
3. Interact with filters to explore insights.
